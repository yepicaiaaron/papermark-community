The domain lists in this folder come from:

- free-domains.json: the `free-email-domains` npm package (MIT,
  https://github.com/Kikobeats/free-email-domains), plus a few common
  providers added by hand.
- disposable-domains.json and disposable-wildcards.json: the
  `disposable-email-domains` npm package (MIT,
  https://github.com/ivolo/disposable-email-domains).
